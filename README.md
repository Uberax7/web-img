# CS2 ImGui Menu Template / Base

A clean, modern Dear ImGui interface implementation for Counter-Strike 2. 
Designed for educational purposes and internal/external DirectX 11 overlay prototyping.

### Features
* Modern Red-themed ImGui UI design
* Multi-tab navigation (Visuals, Settings, System Info)
* Dynamic watermark with FPS & real-time stats
* Lightweight and optimized rendering hook/overlay
